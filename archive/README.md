# Archived development generations

This directory preserves earlier calculator-rendering experiments and version
snapshots for reference. These projects are not part of the maintained fxOGL
library or fxGLMark application and are not covered by the active host CI
workflow.

- `renderer-v1/`: original C renderer and perspective-warp experiments.
- `renderer-v2/`: early C++ block-world renderer.
- `renderer-v3-history/`: historical source snapshots retained under the
  former V3 project's Versions directory.
- `model-renderer/`: separate mesh/model renderer experiment, including its
  source revisions and original model/texture assets.

Generated CMake build output, local VS Code settings and the Blender
`.blend1` autosave backup were removed during repository cleanup. Original
source files, model assets, textures and historical source snapshots were
retained.
